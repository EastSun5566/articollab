Two writers, one Tiptap document.

Each writer is a React tree with a Tiptap editor on the same Articollab Text. Format with the toolbar or the usual shortcuts, pick a language for a code block, press Shift+Enter for a new line, and turn a writer Offline to keep editing until it reconnects. Undo takes back only your own edits, and the server drops links that are not http: or https:. React and Tiptap load from esm.sh.
