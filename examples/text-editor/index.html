Edit locally. Sync when ready.

Two CodeMirror editors, one authoritative document. Local edits stay optimistic until you choose Sync. Reject pending cancels unconfirmed work, not edits the server already accepted.

Each writer shares its selection about once a second, separately from Sync. A shared position follows the text it was anchored to, so it stays put when the other writer edits around it. A position inside text this writer has not synced yet is listed below the editor instead of being drawn in the wrong place.

Sync pauses both editors and is unavailable during text composition. This localhost prototype has no authentication, autosave, undo or reload recovery. Inspect checkpoints before leaving the page.
