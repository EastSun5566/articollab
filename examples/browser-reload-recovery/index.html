Articollab browser reload recovery

Add offline edits, reload this same tab using your browser, then sync. The entire checkpoint is saved in sessionStorage, including pending batches and client identity. No edits are sent automatically.

In-memory mode: keep the same server running. Persistent mode: restart with the same checkpoint directory and port, then reload this same tab and sync. Do not duplicate this tab, copy its checkpoint to another writer, or restore it against a fresh server. A document identity mismatch stops synchronization without discarding pending work. This unauthenticated localhost example does not coordinate writers or promise recovery after closing the tab.
