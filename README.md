# Articollab

Articollab is a TypeScript library for collaborative state. Clients show edits immediately. The server orders commits and decides their effect.

- [Articollab package](packages/articollab/README.md) for installation and a quick start
- [Documentation](https://eastsun5566.github.io/articollab/) for guides and the API reference
- [Examples](examples/README.md) for runnable demos
- [Contributing](CONTRIBUTING.md) for setup, checks and releases
